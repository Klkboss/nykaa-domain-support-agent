# Requirements traceability

Source of truth: [assignment.md](assignment.md) (unmodified). Each row quotes or closely paraphrases one
requirement, with its spec line. "Phase" is the build phase from the owner's plan in PROJECT_STATUS.md.

Status levels (each one includes the one before it):
- **OPEN**: not built.
- **IMPLEMENTED**: code or content exists, but no automated test proves the requirement yet.
- **TESTED**: automated tests pass and a transcript is saved; awaiting the owner's independent review. "TESTED (spike)" means proven only by the Phase 0 spike, not yet by the final component.
- **VERIFIED**: TESTED, and the owner's review of that phase approved it.
