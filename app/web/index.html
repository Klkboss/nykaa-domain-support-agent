Pipeline

How each answer is made

  1. PII masking and prompt-injection check
  2. Retrieval Agent searches the policy base (ChromaDB)
  3. Lookup Agent, the only one allowed, checks the order
  4. Composer writes a structured draft
  5. Groundedness guardrail checks every claim
  6. AutoGen review team approves or trims it
